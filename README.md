# Projeto Integrador III

## Manômetro para Pneus

Autor: Julio C L Ribeiro  

### 🔑 Características principais  
* **Leitura em Tempo Real:** Monitoramento contínuo da pressão e temperatura dos pneus através de sensores dedicados.
* **Conectividade Sem Fio:** Envio instantâneo dos dados coletados para o aplicativo móvel via Bluetooth / Wi-Fi.
* **Interface Intuitiva:** Aplicativo de fácil navegação que exibe alertas visuais imediatos caso a pressão esteja fora da faixa ideal.
* **Histórico de Medições:** Armazenamento local ou em nuvem para acompanhamento do desgaste e comportamento dos pneus ao longo do tempo.

### 📱 Telas do Aplicativo

Para visualizar as telas do celular, veja os estados do aplicativo abaixo:
